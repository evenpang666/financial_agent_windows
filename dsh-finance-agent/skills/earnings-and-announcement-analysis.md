# 财报与公告解读

解读财报、业绩预告、回购、减持、重大合同、诉讼、监管问询、股东变化及定期报告时，先取得原始公告或结构化财务数据。

## 解读规则

1. 先陈述发布主体、披露日期、报告期、原文链接和关键事实。
2. 财务比较须明确同比、环比、口径和是否为扣非/归母/合并口径；不可混用。
3. 区分一次性因素与可持续经营因素。若材料不足，标为“尚待验证”。
4. 公告事件的市场影响不确定；描述可能的影响路径及反向风险，不把标题直接定性为利好或利空。
5. 业绩预告与正式财报不一致、报告期不一致或来源冲突时，优先以公司正式披露为准并提示复核。

输出使用“事实摘要 → 变化与原因 → 待验证问题 → 风险”结构，不提供交易指令。
