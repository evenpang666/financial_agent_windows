# 每日股票研究候选池

当用户要求每日股票推荐、寻找值得研究的 A 股标的或建立候选池时使用本 Skill。该 Skill 生成的是待研究候选，而非个性化买卖推荐。

## 证据流程

1. 调用 `get_market_brief` 和 `get_market_movers`，将异动标的视为候选来源而不是结论。不要因单日涨幅、成交量或新闻标题直接推荐追涨。
2. 从异动列表中选择少量有可验证理由的候选，或优先采用用户给出的行业/代码范围。对每个候选调用 `get_quote_snapshot`、`get_technical_indicators`、`get_fundamentals`、`get_valuation` 和 `get_announcements`。
3. 任何一个候选如缺少公告、财务、估值或行情的关键数据，应降级为“待补数据”，不得用主观叙述补齐。
4. 说明筛选只反映当前可得数据，不能代表未来表现；历史技术指标与异动都可能迅速失效。

## 输出

最多列出 3–5 个“研究候选”，每项包含筛选理由、关键事实与来源、主要风险、反例/失效条件和下一步核验动作。最终标签限定为 `进入观察池`、`继续观察` 或 `排除/待补数据`；不得输出买卖、仓位、价格目标、止损或收益承诺。
