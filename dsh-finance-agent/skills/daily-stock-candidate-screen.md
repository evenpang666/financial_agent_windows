# 每日股票研究候选池

当用户要求每日股票推荐、寻找值得研究的 A 股标的或建立候选池时使用本 Skill。该 Skill 生成的是待研究候选，而非个性化买卖推荐。

## 证据流程

1. 调用 `get_market_brief` 和 `get_candidate_ranking`。排名使用公开的动量、流动性和估值评分，只作为候选来源；不要因单日涨幅、成交量或新闻标题直接推荐追涨。
2. 从排名中选择少量有可验证理由的候选，或优先采用用户给出的行业/代码范围。需要展开时对每个候选调用 `analyze_stock`。
3. 任何一个候选如缺少公告、财务、估值或行情的关键数据，应降级为“待补数据”，不得用主观叙述补齐。
4. 说明筛选只反映当前可得数据，不能代表未来表现；历史技术指标与异动都可能迅速失效。

## 输出

按评分降序用表格列出 3–5 个候选，至少包含排名、代码、名称、评分、买入倾向百分比、卖出倾向百分比、1/5/20 日表现、估值和明确买卖建议；随后说明筛选理由、风险和评分方法。百分比表示证据方向倾向，不是仓位或收益概率；不得承诺收益。
