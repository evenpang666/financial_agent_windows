# 市场事件日评与周评

当用户要求每日大事、每周/月度市场回顾、宏观事件对 A 股的可能影响或开盘日市场简报时使用本 Skill。

## 工作方法

1. 日评调用 `get_market_brief`；周评和月评分别调用 `get_market_events(days=7)` 与 `get_market_events(days=30)`，记录每条快讯的日期/时间。快讯标题只是一条待核验线索。
2. 需要关联用户持仓时，再调用 `get_saved_portfolio`，并只为其中标的调用 `get_announcements`。公司公告优先于泛市场快讯。
3. 日评聚焦可得的当日或最近交易日数据；周评/月评明确统计窗口，并将无法确认日期的快讯单列为“待核验”。
4. 区分已确认事实、可能影响路径和未验证假设。没有原文、发布日期或可得行情支撑时，不扩展成趋势判断。

## 输出

输出“市场快照”“事件清单”“可能影响路径与反例”“持仓相关事项（如适用）”“下一个交易日/下周核验清单”。所有市场判断都附来源和 `as_of`，不使用确定性预测措辞。
