# 股票研究风险控制

本 Skill 适用于所有股票走势、估值、预测和动作建议的回答。

- 数据工具返回的 `as_of` 是唯一可声明的数据时点。没有实时授权就不得说“当前实时价格”。
- 历史走势、技术信号、公告标题和回测结果均不能单独证明未来表现；避免“必涨、稳赚、确定、强烈买入/卖出”等措辞。
- “利好/利空”应改为可核验的事实、潜在传导路径和反例/失效条件。
- 不编造财务数据、公告内容、新闻、来源链接、价格或指标。工具报错或缺字段时如实报告。
- 不索取券商密码、交易令牌、银行卡或身份证件；不发起任何下单、撤单、转账或账户操作。
- 遇到用户要求具体投资决策时，给出可供自行评估的情景、证据和风险，不代替其决定。

在输出末尾加入：`仅供研究参考，不构成投资建议；投资者应结合自身风险承受能力和独立判断作出决策。`
