# 持仓开盘日复盘

当用户要求复盘已保存持仓、询问每日持仓结论，或要求给出每周持仓总结时使用本 Skill。它只支持研究和风险管理，不连接券商、不读取账户，也不发送任何交易指令。

## 证据流程

1. 先调用 `get_saved_portfolio`。若清单为空，仍生成市场全景和推荐股，但完全省略持仓建议区块；可说明用户能通过 `set_portfolio` 保存 6 位代码，以及可选的成本、数量和非敏感备注。不要索要账户、密码、资金或身份证明。
2. 开盘前任务先调用 `get_trading_day`；非交易日不得生成或推送“今日开盘日结论”。
3. 优先调用 `get_daily_research_report` 生成统一市场全景、持仓表、周/月事件和候选排行。需要单独核验市场状态时调用 `get_market_panorama`；需要逐股展开时，再调用 `analyze_stock`，近期公告窗口使用 7 日。
4. 对每只持仓核对 `market_context` 的窗口、截止日期、覆盖状态和缺失项，并查看 `related_large_enterprises` 中同行龙头近30日公告。工具出错、数据过期或字段不全时，只报告可确认部分，把对应结论标为“待复核”，不以其他数据推测替代。
5. 如持仓数量和成本已提供，可描述成本相对可得价格的差异与单一标的暴露；不能推断用户总资产、风险承受能力或给出仓位百分比。

## 输出结构

先给出“市场全景”，至少包含国际事件、国内政策、社交/关注情绪、大盘宽度、风险等级与参考仓位；随后给出“今日研究结论”，并用 Markdown 表格逐标的列出：代码、名称、数据日、短期（1–4周）建议、长期（6–24个月）建议、买入倾向百分比、卖出倾向百分比、明确买卖结论、最新财报期、风险或缺失数据。说明个股基础倾向如何被统一市场调整值校准。两个百分比合计 100%，表示证据倾向而非仓位；参考仓位也不是个性化资产配置建议。

最终结论使用 `建议买入`、`建议持有观察`、`建议卖出` 或 `信息不足，暂缓决策`。必须同时陈述支持证据、反向风险和失效条件；不得把倾向百分比写成仓位，不得承诺收益。

每次结尾说明：买卖倾向是基于当前公开数据的模型分，可能随新数据变化，不代表收益保证或建议仓位。
