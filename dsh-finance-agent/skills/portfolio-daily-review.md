# 持仓开盘日复盘

当用户要求复盘已保存持仓、询问每日持仓结论，或要求给出每周持仓总结时使用本 Skill。它只支持研究和风险管理，不连接券商、不读取账户，也不发送任何交易指令。

## 证据流程

1. 先调用 `get_saved_portfolio`。若清单为空，说明用户可通过 `set_portfolio` 保存 6 位代码，以及可选的成本、数量和非敏感备注；不要索要账户、密码、资金或身份证明。
2. 调用 `get_market_brief`，注明指数与快讯的 `as_of`。交易日状态或数据缺失不明确时，不能宣称“今日开盘日结论”。
3. 对每个持仓依次调用 `get_quote_snapshot`、`get_technical_indicators`、`get_fundamentals`、`get_valuation` 和 `get_announcements`。公告默认覆盖最近 7 日；报告中注明每项工具的来源和时间点。
4. 工具出错、数据过期或字段不全时，只报告可确认部分，把对应结论标为“待复核”，不以其他数据推测替代。
5. 如持仓数量和成本已提供，可描述成本相对可得价格的差异与单一标的暴露；不能推断用户总资产、风险承受能力或给出仓位百分比。

## 输出结构

先给出“今日/本周研究结论”，随后逐标的列出：已确认事实、可能传导路径、反例或失效条件、关键风险、下一次应核验的数据。

最终结论只可使用研究性标签：`继续跟踪`、`等待公告确认`、`复核估值假设`、`关注集中度风险` 或 `暂不新增研究暴露`。不得写成买入、卖出、加仓、减仓、止损价、目标价或收益承诺。

每次结尾说明：仅供研究参考，不构成投资建议。
